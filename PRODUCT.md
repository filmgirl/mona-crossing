# Mona Crossing
<!-- impeccable:product-schema 1 -->

## Platform
web

## Users and Purpose
Visitors to the Commit Cabinet and the standalone public game want a quick,
playable GitHub-themed crossing game, using keyboard or touch without an account.

## Operating Context
The standalone game lives in filmgirl/mona-crossing and deploys to GitHub Pages.
The cabinet embeds the complete document in a sandboxed iframe; it owns no game
audio, score, or pause bridge. Integration is maintained separately.

## Capabilities and Constraints
Mona crosses bug traffic, rides commit logs and PR ferries, and reaches five main
gardens. Three hearts, countdown, local best, rounds, pause, restart and mute are
required. Simulation is deterministic and independent of rendering. No backend,
telemetry, external runtime requests, copyrighted music or copied reference maps.

## Brand Commitments
The approved visual world is a complete original candy-pastel pixel neighborhood,
inheriting the cabinet's recognizable pixel Octocat and locally hosted Silkscreen.
Reference images inform palette and craft only; they are not shipping assets.
GitHub's character rights remain separate from this game's source-code license.

## Accessibility
Visible keyboard focus, named controls, touch D-pad, readable state changes,
reduced ornamental motion and no default flicker. Canvas gameplay is visual;
the game does not claim a nonvisual play mode.
